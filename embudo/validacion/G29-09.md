## Borradores de 2 publicaciones
**Post 1: "How I structure an IO list so it survives handover"**
I've been through a few handovers where the IO list and the program drifted apart. What worked: one row per point with rack/slot/channel, PLC tag, field device tag, terminal, signal type, range and spare/used; every program tag appears in the list and vice versa; revision code on every export. Template link in comments. How do you handle revisions? Curious what others do, especially with TIA vs Studio 5000 exports.

**Post 2: "Step-by-step: exporting I/O config from TIA Portal and Studio 5000 to Excel"**
Short guide with screenshots: Address Overview and AML/Excel export in TIA, L5X export in Studio 5000 and what each includes and misses (e.g., native CSV often gives an unreadable module list). Known gaps and workarounds listed at the end. Which parts do you still fix by hand? (No product mention; mention of my project only if someone asks.)
